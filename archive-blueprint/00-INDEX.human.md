## ⛔ 꼭 지켜야 할 규칙 — 변경 시 동기화

아카이브를 만지는 모든 사람·AI가 지켜야 합니다:

- **글 내용만 바꿀 때** (아티클 추가·수정·삭제) → 이 청사진은 안 건드려도 됩니다. 목차(`archive-structure.md`)만 맞추면 됩니다.
- **프로그램·검색방식·파일구성·실행방식을 바꿀 때** → **반드시 이 청사진 문서도 같이 고치고, `CHANGELOG`에 무엇을 왜 바꿨는지 기록**해야 합니다.

> 이걸 안 하면 청사진이 실제와 어긋나서, 다음에 작업하는 AI가 틀린 설명을 보고 엉뚱하게 고칩니다.
> 그래서 동기화는 "하면 좋은 것"이 아니라 **작업의 일부**입니다.

## 한 줄 요약

> **데이터·화면·검색 기능을 전부 담은 HTML 파일 하나 + 그걸 다루는 파이썬 도구 3개.**
> 무거운 데이터베이스나 서버 설치 없이, 파일 몇 개로 굴러가는 가볍고 이식성 좋은 사내 지식 아카이브입니다.

## 원본 아카이브를 이루는 파일들

| 파일 | 한 줄 설명 |
|------|-----------|
| `archive.html` | **아카이브 본체.** 수십 개의 글(아티클)과 화면, 디자인, 검색 기능이 전부 이 파일 하나에 들어있습니다. |
| `archive-structure.md` | 목차 역할. AI가 매번 거대한 HTML 전체를 읽지 않도록 글 목록만 따로 둔 가벼운 색인입니다. |
| `archive-intake.py` | 새 정보를 넣기 전에 **"이미 있는 내용인지, 기존과 충돌하는지, 어디에 넣어야 하는지"**를 자동으로 알려주는 도구. |
| `archive-menu.py` | 메뉴를 눌러가며 검색·입력·현황 확인을 할 수 있는 대화형 화면. |
| `archive-server.py` | **AI 검색 서버.** 브라우저에서 질문하면 PC에 설치된 Claude가 아카이브를 근거로 답해줍니다. 별도 요금/키가 필요 없습니다. `--share`로 같은 네트워크 동료와 공유 가능. |
| `1~5_*.bat` | **실행/종료 단축 파일.** 더블클릭으로 개인모드 켜기(1)·공유모드 켜기(2)·개인종료(3)·공유종료(4)·전체종료(5). |

## 왜 이렇게 만들었나 (설계 철학)

1. **이식성** — 파일만 복사하면 어디서든 열립니다. 인터넷이 끊겨도 됩니다.
2. **단순함** — 데이터베이스 설치, 서버 구축 같은 진입장벽을 없앴습니다.
3. **검색 친화** — 모든 글에 검색 키워드(`data-tags`)를 붙여서 사람도 AI도 쉽게 찾습니다.
4. **안전** — 비밀번호·IP·계정 같은 민감정보는 절대 저장하지 않습니다.
5. **AI 결합** — PC에 이미 로그인된 Claude를 그대로 활용해, 추가 비용 없이 자연어 질문이 가능합니다.
