# 개요 · 아키텍처 · 기술스택 (사람용)

## 전체 그림

```
  archive.html  ← 지식 본체 (글·화면·디자인·검색이 전부 이 한 파일에)
       ↑
  archive-structure.md  ← 목차 (AI가 매번 본체 전체를 안 읽도록)
       ↑
  파이썬 도구 3개
   ├ archive-intake.py  : 새 정보 넣기 전 중복·충돌 검사
   ├ archive-menu.py    : 메뉴 눌러가며 검색·입력
   └ archive-server.py  : 브라우저 AI 검색 (PC의 Claude 사용)
```

## 기술스택 — "일부러 최소한으로"

| 구분 | 사용 기술 | 왜 이걸 골랐나 |
|------|----------|----------------|
| 화면·데이터 | 순수 HTML + CSS + 자바스크립트 | 설치할 게 없음. 브라우저만 있으면 열림. |
| 도구 | 파이썬 기본 기능만 (추가 설치 0) | 비개발자도 `python 파일.py` 한 줄로 실행 |
| AI | PC에 깔린 Claude Code | 추가 요금·API 키 불필요, 사내 데이터가 밖으로 안 나감 |
| 저장 | 그냥 파일 | 데이터베이스 설치/관리 부담 없음 |

> 핵심 철학: **"인수인계 받는 사람이 개발자가 아니어도 굴릴 수 있어야 한다."**
> 그래서 무거운 기술을 일부러 다 뺐습니다.

## archive.html 은 어떻게 생겼나

하나의 HTML 파일이지만 안은 3부분으로 나뉩니다:

1. **디자인(CSS)** — 맨 위에 색깔·박스·표 스타일이 정의돼 있습니다. (강조박스, 경고박스, 프로세스 흐름도 등)
2. **사이드바 메뉴** — 왼쪽에 카테고리별 글 목록. 카테고리마다 글 개수가 숫자로 표시됩니다.
3. **글(아티클)들** — 각 글은 고유 ID와 검색 키워드(`data-tags`)를 달고 있습니다. 이 키워드가 검색의 핵심입니다.

글은 5개 카테고리로 분류됩니다: **기초용어 / 프로세스 / 기술설정 / 트러블슈팅 / 운영 참조 매뉴얼**.

## AI 검색은 어떻게 작동하나

브라우저에서 질문을 입력하면:

1. 질문에서 핵심 단어를 뽑고, **비슷한 말로 넓힙니다** (예: "월간" → "월말·마감·결산"도 같이 찾음).
2. 아카이브에서 가장 관련 있는 글 3개를 골라냅니다. (제목에 키워드가 있으면 점수를 더 줍니다)
3. 그 3개 글 내용을 Claude에게 넘기면서 **"이 자료를 근거로 답해라"**라고 지시합니다.
4. Claude의 답변과 함께, 근거가 된 글로 가는 버튼을 보여줍니다. 답이 나오면 화면이 자동으로 그 글까지 스크롤되고 잠깐 노랗게 강조됩니다.

이 모든 게 **PC에 설치된 Claude로 돌아가므로, 사내 자료가 외부로 나가지 않고 별도 비용도 없습니다.**

## 같은 네트워크에서 공유하기

`archive-server.py --share` 로 실행하면, 같은 사무실 네트워크를 쓰는 동료가
`http://(내 PC의 IP):5174` 주소로 접속해 똑같이 보고 검색할 수 있습니다.
(방화벽이 막으면 안내 문구대로 규칙을 한 번 추가하면 됩니다.)
