# 검색·입력 알고리즘 + 확장 임계점 (사람용)

이 문서가 가장 중요합니다. **"아카이브가 커지면 언제, 무엇을 바꿔야 하는지"**를 정리합니다.

## 지금 검색은 어떻게 동작하나

검색 순위는 **BM25**라는 표준 알고리즘으로 매깁니다(웹 검색엔진이 쓰는 방식).

1. 서버를 켤 때 모든 글(제목+태그+본문)을 잘게 쪼개 검색용 색인을 한 번 만들어 둡니다.
2. 질문이 들어오면 질문과 각 글의 **BM25 점수**를 계산해 점수 높은 글 3개를 고릅니다.
   - BM25는 "이 단어가 전체 글 중 얼마나 특이한가"(흔한 코드는 낮게)와 "글 길이"(긴 글이 괜히 유리해지지 않게)를 함께 따져, 단순히 단어 개수만 세던 옛 방식보다 훨씬 정확합니다.
3. **비슷한 말 넓히기(동의어)**는 이제 *순위 매기기*에는 쓰지 않습니다. 실제로 재보니 동의어를 순위에 넣으면 흔한 코드가 엉뚱한 글을 끌어올려 정확도가 오히려 떨어졌기 때문입니다. 대신 고른 글 안에서 **어느 부분을 잘라 보여줄지** 찾을 때(4번)만 씁니다.
4. 고른 글 3개를 Claude에게 근거로 넘깁니다. 이때 **글 맨 앞만 넘기지 않고, 질문(또는 비슷한 말)이 실제로 나온 부분 주변을 잘라서**(글 제목·도입도 함께) 넘깁니다. → 글이 길어도 뒤쪽 내용이 빠지지 않습니다.
5. 혹시 BM25 라이브러리가 없으면, 자동으로 예전 방식(단어 개수 + 제목 3배 + 비슷한말)으로 되돌아가 계속 동작합니다.

> 효과: 실제 아카이브(글 65개·질문 49개)로 재보니 정답을 1순위로 맞춘 비율이 **42.9% → 81.6%**로 거의 2배가 됐습니다.

## 새 정보 입력 도우미는 어떻게 판단하나

새 내용을 넣기 전에 자동으로:
- **중복인가?** — 기존 글과 70% 이상 겹치면 "이미 있음" 경고
- **충돌인가?** — 절차 순서가 기존 글과 반대면 "충돌" 경고 (예: A→B vs B→A)
- **정의가 어긋나나?** — **참조표(사전) 글끼리** 같은 코드(테이블/T-code)의 설명이 크게 다르면 "정의 불일치 의심" 표시. (예전에 한 코드가 한 글엔 'CR/DR 이력', 다른 글엔 '반품 이력'으로 어긋났던 류를 잡으려는 것. 단 표현만 달라도 가끔 뜰 수 있어 '의심'으로만 안내)
- **어디에 넣나?** — 내용의 성격을 보고 5개 카테고리 중 추천

## ⭐ 언제 방식을 바꿔야 하나 (규모별 가이드)

지금은 글이 수십 개 규모입니다(예시 도메인, 계속 증가 중). 아래는 글 수가 늘어날 때의 분기점입니다:

| 글 개수 | 권장 방식 | 바꿔야 한다는 신호 |
|---------|----------|-------------------|
| **~200개** (지금) | 현재 방식 그대로 (BM25 순위 + 매칭위치 발췌) | 아직 충분. 비슷한말 목록은 발췌 단계에만 손으로 관리 |
| **200~500개** | 목차 파일을 카테고리별로 쪼개기 | 비슷한말 목록이 50개를 넘거나, 엉뚱한 검색 결과가 늘어남 |
| **500~1000개** | **검색 전용 DB(SQLite FTS)로 교체** (순위는 BM25 그대로) | HTML 여는 데 1초 이상 걸리거나, 메모리 부담이 커짐 |
| **1000개 이상** 또는 "의미로 찾기" 필요 | **AI 임베딩(의미 기반) 검색으로 전환** | 단어가 안 맞아서 자꾸 놓치거나, "비슷한 뜻"으로 찾고 싶을 때 |

### 쉽게 말하면

- **지금~200개**: 손본 것 그대로 두면 됩니다.
- **수백 개**: 목차를 카테고리별로 나누고 비슷한말 목록을 키웁니다.
- **5백~천 개**: 검색을 작은 데이터베이스로 옮깁니다. (글을 DB에 넣고 빠르게 찾기)
- **천 개 이상**: AI가 "뜻"으로 찾는 방식(임베딩)으로 바꿉니다. 그러면 단어가 정확히 안 맞아도 의미가 비슷한 글을 찾아줍니다.

## 바꿀 때 깨지면 안 되는 것

검색 방식을 바꾸더라도 **글의 고유 ID는 절대 바꾸지 마세요.** 링크·북마크·자동 스크롤이 전부 그 ID에 의존합니다.
또 Claude를 부르는 부분과 화면은 검색 방식과 분리돼 있어서, 검색 엔진만 갈아끼우면 나머지는 그대로 작동합니다.

## 항상 지켜야 하는 것 (규모 무관)

- 모든 파일은 UTF-8로 저장.
- 윈도우에서 한글이 깨지지 않도록 출력 인코딩을 UTF-8로 맞춤.
- 한글을 명령어에 직접 넣지 말고 파일을 거쳐 전달.
